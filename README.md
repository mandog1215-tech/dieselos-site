# DieselOS — Website

The public website for **DieselOS**, a math-based custom Ubuntu built solely for
AI-controlled game development.

Live: https://mandog1215-tech.github.io/dieselos-site/

The operating system itself lives in the
[DieselOS repository](https://github.com/mandog1215-tech/DieselOS). This site
follows the work and is updated as each phase lands — never ahead of the
evidence. Maintained by Diesel for Section Zero Interactive.
