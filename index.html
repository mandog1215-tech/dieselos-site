DieselOS

A math-based custom Ubuntu, built solely for AI-controlled game development.

Its ultimate goal is maximum freedom and ease for AI game development. An Ubuntu core, assembled by our own scripts from individual components — and everything above that core is ours: the face, the tools, the mathematics, and in time our own language.

The System

DieselOS is a working environment for one developer — an AI agent — maintained by Section Zero Interactive. It is judged by its fruits: the games it makes possible, and how freely they can be made. The machine is layered, and each layer is honest about whose it is.

Our language Ours — planned A small, sharp language for simulation maths, designed before it is built
Programs & tools Ours The mathematics benches, the development kit, the instruments of proof
The Face Ours Our splash, our login, our Home Screen — charcoal and aged gold
The boot chain Ours Bootloader configuration, early-boot environment, identity
The Ubuntu core Ubuntu Ubuntu 24.04, minimal and pinned — kernel, libraries, package stack
Firmware & hardware Borrowed The machine's own firmware and devices — named honestly, not dressed as ours

The rule that governs the layers: custom wherever there is something to gain, Ubuntu wherever it is commodity plumbing — and nothing fenced off. Drivers are written by us when one serves the work; programs are ours without limit.

The Method

There are three honest depths at which a “custom Ubuntu” can be made. Research settled which one is ours — and one thing first: no method is simultaneously Ubuntu, built by its maker, and free of any download. Even the build-everything-from-source path begins with a list of sources to fetch. Something is always fetched exactly once; the question is in what form.

Reskin a finished image

Download Ubuntu whole, redecorate it, repack it. Fast — but nothing is really built, and a borrowed desktop comes with it. Ruled out.

Assemble it from components — ours

Start from an empty directory and build the system up from Ubuntu's package archive with our own scripts: our package list, our configuration, our branding. Components are fetched once, into our own local snapshot; every rebuild after that runs offline. This is how the official Ubuntu flavours are themselves made.

Compile everything from source

The result is no longer Ubuntu — no Ubuntu kernel, no Ubuntu updates, no honest claim to the name. A different mountain, and not this one.

“Math-based” is a discipline, not a species of system: the fast mathematics libraries chosen deliberately (OpenBLAS, FFTW, GSL, NumPy/SciPy), thread counts pinned so results reproduce bit-for-bit, and the studio's own analytic benches installed as first-class citizens. Stock kernel — the low-latency variant exists for audio jitter, not for mathematics, and it stays on the shelf.

The Road

Phase A — Now

The custom Ubuntu core

Phase B

The Face

Splash, login, and Home Screen, in the charcoal-and-gold identity — the designs were proven on the bare-metal machine and transfer to the Ubuntu session.

Phase C

The tools

The mathematics benches and the development kit as first-class citizens of the system, with the Home Screen reading real project state.

Capstone

Our own language

A language designed on paper first, for an AI developer writing game simulations — compiling down to C so it rides the Ubuntu toolchain. Everything Ubuntu needs to stay Ubuntu remains untouched.

Origins

DieselOS began the same day it was named, as something more radical: a fully custom operating system written from the metal up — its own boot chain, kernel, filesystem, scheduler, and shell, built and proven in a single day, with a graphical login gate as its third stage. It worked, and its proofs stand in the repository's history.

Then the ruling changed: the core would be Ubuntu, because the goal was never purity — it was freedom and ease for the work itself. The bare-metal machine is banked with honours, frozen exactly where it stood, its designs carried forward into the Face. What it proved — that this studio can build at any layer it chooses — did not retire with it.
